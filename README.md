# MyLadyAngel Links

A lightweight, responsive link hub for **MyLadyAngel**.

## Features

- Static HTML/CSS/JavaScript
- Mobile-first responsive layout
- No frameworks or build step required
- SEO and Open Graph metadata
- GitHub Pages compatible
- Original implementation inspired by the simplicity of link-directory repositories

## Run locally

Open `index.html` in a browser, or serve the directory with any static web server.

## Deploy with GitHub Pages

1. Create a new GitHub repository.
2. Upload the contents of this folder to the repository root.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`.
6. Save and wait for GitHub Pages to publish the site.

## Customize

Edit `index.html` to change links and copy. Edit `assets/css/style.css` to change the visual design.
